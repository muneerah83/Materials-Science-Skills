# Structural and Advanced Ceramics — Reviewer Delta
# Adds to the ceramics-template. Load ceramics.md first, then this file.

## Domain-specific review axes

- **Hall-Petch validation**: If grain-size toughening is claimed, Hall-Petch analysis (KIC vs. d⁻¹/²)
  is expected. Strength-grain size correlation alone does not prove the mechanism.
- **ZrO₂ phase transformation**: t→m transformation must be verified by Raman or XRD.
  Raman is preferred for surface/subsurface transformation assessment; XRD for bulk.
- **Fracture toughness method disclosure**: SENB or SEPB methods are acceptable.
  Vickers indentation IF method alone is not accepted by Acta Materialia / JECS without independent validation.
- **TBC/EBC applications**: Thermal cycling data required; isothermal oxidation alone
  does not characterize thermal barrier performance.

## Domain-specific fatal flaws

- Grain refinement toughening without Hall-Petch analysis.
- ZrO₂ phase claimed stable without Raman/XRD verification after sintering.
- KIC from indentation only, not validated by SENB or SEPB.
- TBC performance from isothermal oxidation only — thermal cycling not assessed.

## Domain-specific reviewer questions

- "Is a Hall-Petch plot (KIC vs. d⁻¹/²) provided for grain-boundary toughening claims?"
- "Is the ZrO₂ t→m phase verified by Raman (surface) and XRD (bulk) after sintering?"
- "What method was used for KIC (SENB, SEPB, or indentation)? If indentation, is it validated?"
- "Is thermal cycling data provided for thermal barrier applications?"
