# Waterproofing and Sealants — Reviewer Delta
# Adds to the civil-template. Load civil.md first, then this file.

## Domain-specific review axes

- **Failure mode identification**: Adhesion pull-off test must identify whether failure is cohesive (within material)
  or adhesive (at substrate interface). Adhesion strength without failure mode is incomplete.
- **Movement capability**: Sealant joint performance requires cyclic loading data (extension/compression cycles).
  Static tensile strength alone does not characterize sealant service performance.
- **Aging duration**: Durability claims require sufficient accelerated aging (UV, heat, water immersion).
  Aging < 30 days is generally insufficient for a durability claim.
- **Substrate surface preparation**: Adhesion claims must state the substrate preparation method
  (cleaning, priming, surface roughness). Same material can give 3× difference on primed vs unprimed concrete.

## Domain-specific fatal flaws

- Pull-off adhesion without failure mode (cohesive/adhesive) classification.
- Movement capability claimed from static tensile data only.
- Short-term aging (< 30 days) presented as durability validation.
- No substrate surface preparation details reported.

## Domain-specific reviewer questions

- "What is the failure mode in the adhesion test: cohesive, adhesive, or mixed?"
- "Is cyclic joint movement data provided (extension/compression cycles)?"
- "What is the total UV/heat/water immersion aging duration?"
- "What surface preparation was applied to the substrate before application?"
