# Nanomaterials — Family Reviewer Template
# Applies to all nano sub-domains. Load the matching delta/ file for sub-domain-specific criteria.

## Shared review axes (all nano systems)

- **Size characterization completeness**: TEM size distribution from ≥ 100 particles required.
  Size from XRD Scherrer alone is crystallite size, NOT particle size — these are different quantities.
- **DLS reporting**: PDI value AND distribution weighting (intensity/number/volume) must both be stated.
  A DLS result without PDI cannot assess polydispersity.
- **Colloidal stability**: Zeta potential AND aggregation state under relevant conditions must be assessed.
  A single-point zeta value is insufficient; pH and ionic strength dependence matter.
- **Batch reproducibility**: Results from multiple synthesis batches must be shown.
  Single-batch data cannot support a synthesis protocol claim.
- **Scale claim**: "Scalable synthesis" requires large-area or large-quantity uniformity statistics, not single-sample data.

## Common fatal flaws (all nano systems)

| Flaw | Consequence |
|---|---|
| Size from Scherrer (XRD) reported as particle size | Physically incorrect — Scherrer = crystallite domain |
| "Monodisperse" claimed without size distribution histogram | Unverifiable |
| DLS without PDI or weighting info | Polydispersity not assessed |
| Single synthesis batch presented | Protocol not validated |
| Colloidal stability from one pH/ionic strength point only | Incomplete stability claim |

## Shared reviewer questions

- "How many particles were counted for the TEM size distribution? (≥100 required)"
- "What is the PDI from DLS? Intensity, number, or volume weighting?"
- "Were results reproduced across multiple synthesis batches?"
- "Is colloidal stability assessed across the relevant pH and ionic strength range?"
- "Is the XRD crystallite size distinct from particle size in the analysis?"
