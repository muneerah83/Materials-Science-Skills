# Metals and Alloys — Figure Rules

## Technical requirements per figure type
- **Stress-strain curve**: report UTS, yield strength, elongation-to-fracture; multiple curves per condition on one plot; specimen orientation stated
- **Optical micrograph**: etching method identified; scale bar; grain size annotation or separate histogram
- **SEM fractography**: two magnifications (low overview + high detail); failure mode labelled (ductile/brittle/mixed)
- **EBSD map**: IPF colour key shown; step size and indexing rate reported
- **TEM micrograph**: scale bar; precipitate size distribution histogram if size is claimed
- **XRD pattern overlay**: peak labels with phase; ICDD reference card numbers cited; 2θ range stated
- **Hardness profile**: indentation locations marked on micrograph; load and dwell time stated

## Reviewer-sensitive pitfalls
- ⚠️ Stress-strain curves without specimen orientation or gauge length.
- ⚠️ Fracture mechanism claimed without fractography (SEM).
- ⚠️ EBSD maps without step size or indexing rate.
- ⚠️ Grain size stated without measurement standard (ASTM E112 or equivalent).
- ⚠️ Hardness values without indenter type and load specification.

## Caption boundary phrases
- `Engineering stress-strain curves of [alloy] after [heat treatment]. Specimens oriented [direction]; gauge length [value] mm.`
- `SEM fractographs of tensile specimens: (a) [condition A] showing [feature], (b) [condition B] showing [feature].`
- `EBSD IPF maps of [alloy]: (a) as-received, (b) after [processing]. Step size: [value] µm; indexing rate: [value]%.`
- `XRD patterns of [alloy] identifying [phases]. Reference patterns: ICDD [card numbers].`
